# Contributing

Edit `index.html` and the illustrations in `assets/`. Keep the page simple, accessible, and usable on small screens.

Run `node scripts/build-site.cjs` to create `dist/`. Preview that folder in a browser before publishing changes. Only the built page and its assets are deployed; generated files are not committed.

Pushes to `main` publish through [GitHub Pages](https://ai-for-linguistics.github.io/aiforlinguistics/). The workflow is in `.github/workflows/pages.yml`.

See [illustration sources](docs/ASSETS.md) and [license notices](THIRD_PARTY.md) when changing artwork.
